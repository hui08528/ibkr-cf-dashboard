🚀 部署到 Netlify 指南

1

注册 Netlify 账号

访问 app.netlify.com，使用 GitHub / GitLab / 邮箱注册。

2

方式 A：拖拽部署（最快）

在 Netlify 首页找到 Drop site or upload a folder，将本站文件夹整个拖进去，几秒即部署完成。

3

方式 B：连接 Git 仓库（推荐）

Add new site → Import an existing project，选择 GitHub 仓库，Build command 留空，Publish directory 填 .（根目录）。

4

自定义域名（可选）

Site settings → Domain management → Add custom domain，按提示配置 DNS 即可。

5

配置 IBKR Flex Web Service

在 IBKR Client Portal 创建 Flex Query，并在 Netlify 环境变量里添加 IBKR_FLEX_TOKEN 和 IBKR_FLEX_QUERY_ID。

6

配置财报日历（可选）

在 Alpha Vantage 申请 API Key，并在 Netlify 环境变量里添加 ALPHA_VANTAGE_API_KEY。

7

Netlify配置文件

项目根目录的 netlify.toml 已包含静态发布目录、Functions 目录和头部规则，可直接使用。
