🚀 部署到自托管服务器指南

1

准备一台海外 VPS

推荐香港 / 日本 / 新加坡节点，1C1G 即可（免 ICP 备案，国内直连效果好）。详细选购建议见 DEPLOY.md。

2

安装运行环境

在 VPS 上安装 Node.js 20 LTS（及以上）、nginx、certbot。

3

获取代码并安装依赖

把仓库 clone 到服务器（如 /opt/ibkr-cf-dashboard），执行 npm ci --omit=dev。

4

配置环境变量

复制 .env.example 为 .env，填入 IBKR_FLEX_TOKEN、IBKR_FLEX_QUERY_ID（必填），ALPHA_VANTAGE_API_KEY（可选）。执行 chmod 600 .env。

5

启动后端服务

推荐用 Docker Compose（docker compose up -d --build），以后加后端服务、数据库都往 docker-compose.yml 里加容器即可。不想用 Docker 也可用 PM2 / systemd（详见 DEPLOY.md 附录）。

6

配置 nginx 反代 + HTTPS

参考 deploy/nginx.conf 配置反代与安全头，用 certbot --nginx 一键签发 HTTPS 证书。

7

访问保护（强烈建议）

页面和 API 会返回你的真实持仓数据。建议在 nginx 开启 Basic Auth（htpasswd），零前端改动即可整站保护。详见 DEPLOY.md。
